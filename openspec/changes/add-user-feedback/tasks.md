# Tasks

Ordered so each phase is independently revertible and leaves the application working. Backend before frontend, because the frontend calls the API; the read tool before the UI, because a channel nobody can read is not worth shipping.

- [x] 3.3 Print submitted text as data, never raw — strip or escape control characters and ANSI escape sequences before printing. The C1 range is stripped in its UTF-8 form too, which the obvious `tr` range alone would have missed.
